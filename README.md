# 🛡️ Phishing Email Simulator

A Python-based cybersecurity awareness training tool with a professional Tkinter GUI.

## Features

- 📧 10 simulated emails
- 🚨 Phishing detection
- ✅ Legitimate email detection
- 💡 Explanation after each answer
- 🔎 Phishing indicators
- 📊 Score and progress tracking
- 🏆 Final performance report
- 🎨 Professional dark-themed GUI
- 🔄 Restart option

## Technologies Used

- Python
- Tkinter
- ttk

## How to Run

Open the project in VS Code and run:

```bash
python phishing_simulator.py
